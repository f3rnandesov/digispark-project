# Digispark USB HID Lab

Projeto experimental com **Digispark ATtiny85** utilizando **C++ e Arduino IDE**, com foco no estudo de USB HID, automação de teclado e interação controlada com sistemas operacionais.

## Sobre o projeto

Este repositório reúne experimentos realizados com o Digispark ATtiny85 para compreender como um microcontrolador pode atuar como um dispositivo **USB HID (Human Interface Device)**.

O projeto começou com testes básicos de programação do ATtiny85 e evoluiu para automações envolvendo teclado USB, como abertura de terminal e execução de comandos previamente definidos.

O desenvolvimento é realizado em ambiente de laboratório e prioriza testes controlados, documentação e separação entre código experimental e versões estáveis.

## Objetivos

* Aprender programação de microcontroladores com C++.
* Entender o funcionamento do Digispark ATtiny85.
* Utilizar a biblioteca `DigiKeyboard`.
* Estudar USB HID.
* Automatizar entradas de teclado em ambiente controlado.
* Estudar diferenças de interação entre sistemas operacionais.
* Organizar o desenvolvimento utilizando Git e GitHub.
* Posteriormente estudar a implementação dessas funcionalidades em C puro.

## Hardware

* Digispark ATtiny85
* Cabo/conector USB compatível
* Computador para desenvolvimento e testes

## Software

* Arduino IDE
* Digistump AVR Boards
* Micronucleus
* Biblioteca DigiKeyboard
* Git
